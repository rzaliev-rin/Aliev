# Бот «Выкуп и комиссия» — пошаговый запуск

Инструкция для человека без IT-опыта. Делайте шаги по порядку. Где написано
«выполните команду» — команду нужно скопировать целиком и вставить в окно
сервера (как вы делали для бота метрики), затем нажать Enter.

## Что получится

Когда продавец готов к выкупу или комиссии, бот:

1. создаёт в Битрикс24 карточку клиента (лид или сделку) со всей перепиской;
2. присылает в рабочий чат салона в MAX короткое сообщение:

```
🔥 Выкуп — клиент готов к разговору

👤 Клиент: Сергей, +7 999 123-45-67
📝 Готов показать машину в субботу, ДТП не было. Звонить: после 18. Ожидания по цене: 2,3 млн.

🚗 Toyota Camry, 2019 г., 87 000 км, 2 400 000 ₽, Тюмень
Объявление: https://auto.drom.ru/…
📋 Битрикс24: https://ваша-компания.bitrix24.ru/crm/lead/details/1234/
Салон: Тойота Центр Тюмень
```

Если Битрикс24 недоступен, клиент всё равно придёт в чат, с пометкой, что
карточка не создана, а владелец бота получит предупреждение.

## Что понадобится (список)

| Что | Где взять | Шаг |
|---|---|---|
| Токен нового бота MAX | @MasterBot в MAX | 1 |
| Ключ Anthropic API (ИИ) | console.anthropic.com | 2 |
| Адрес вебхука Битрикс24 | в вашем Битрикс24 | 3 |
| Сервер | тот же, где бот метрики | 4 |
| Отдельный аккаунт на Дроме (потом Авито/Авто.ру) | регистрация на сайте | 5 |
| Компьютер с Windows/Mac | чтобы один раз войти в аккаунт | 5 |

## Шаг 1. Новый бот в MAX

1. В MAX найдите `@MasterBot`, напишите `/newbot`.
2. Имя — например «Выкуп и комиссия АСП», username — любой свободный.
3. MasterBot пришлёт **токен** (длинная строка). Сохраните его — он нужен в шаге 4.
   Это **новый** бот, не бот метрики: у них разные токены.

## Шаг 2. Ключ Anthropic API (мозг агента)

1. Откройте console.anthropic.com, зарегистрируйтесь.
2. Раздел **Billing** — привяжите карту и пополните баланс (оплата по факту
   использования).
3. Раздел **API Keys** → **Create Key** → скопируйте ключ (начинается с `sk-ant-`).
   Ключ показывается один раз.

> ⚠️ Важно: Anthropic официально не работает в России — регистрация, оплата
> российскими картами и запросы с российских серверов могут не проходить.
> Решите это до запуска: например, аккаунт оформляет партнёр или юрлицо в
> стране, где сервис доступен. Если это невозможно — агента можно перевести на
> российскую модель (YandexGPT или GigaChat), это отдельная доработка.

## Шаг 3. Битрикс24: входящий вебхук

Вебхук — это «ключ», по которому бот может создавать карточки в вашем CRM.
Делает администратор Битрикс24.

1. В Битрикс24 слева: **Разработчикам** (или **Приложения → Разработчикам**).
2. Вкладка **Другое** → **Входящий вебхук**.
3. В «Настройке прав» отметьте **CRM (crm)**. Желательно ещё **Пользователи (user)** —
   тогда бот сможет показать список сотрудников с их номерами (ID).
4. Нажмите **Сохранить**. Скопируйте строку **«Вебхук для вызова rest api»**, она
   выглядит так: `https://ваша-компания.bitrix24.ru/rest/15/abc123xyz/`.
   Это секрет — не пересылайте его в общие чаты.

Если пункта «Разработчикам» нет — нужны права администратора портала, или ваш
тариф Битрикс24 не даёт вебхуки; уточните у администратора.

**Лид или сделка?**
- **Лид** (по умолчанию) — «входящая заявка», менеджер потом сам переводит её в сделку.
  Проще для старта.
- **Сделка** — бот сразу создаёт контакт клиента и сделку в нужной воронке
  (например, отдельная воронка «Выкуп»). Номер воронки виден в адресе страницы,
  когда вы её открываете: `…/crm/deal/category/3/` → номер `3`.

**Кто ответственный.** Пока простое правило: если указать несколько сотрудников,
бот назначает их **по очереди**. Если никого не указать — ответственным будет тот,
кто создал вебхук. Своё правило распределения (по салону, по марке, по загрузке)
добавим, когда решите.

## Шаг 4. Установка на сервер

Можно ставить на тот же сервер, где бот метрики — они не мешают друг другу.

1. Подключитесь к серверу так же, как при установке бота метрики (консоль в панели
   хостинга или программа SSH).
2. Выполните команду:

   ```bash
   curl -sL https://raw.githubusercontent.com/rzaliev-rin/Aliev/claude/peaceful-dijkstra-2793bo/deploy/install_buyout.sh | bash
   ```

3. Подождите 5–10 минут (ставится браузер для работы с сайтами). Скрипт задаст
   вопросы — вставляйте ответы и нажимайте Enter:
   - **токен нового бота** — из шага 1;
   - **ваш ID в MAX** — просто Enter, если вы владелец бота метрики (4852272);
   - **ключ Anthropic** — из шага 2 (можно Enter и добавить позже);
   - **адрес вебхука Битрикс24** — из шага 3 (можно Enter и добавить позже).
4. В конце должно быть: «ГОТОВО: бот «Выкуп и комиссия» запущен». Напишите
   новому боту в MAX `/start` — придёт меню.

**Если что-то добавляете позже** (ключ, вебхук, ответственных):

```bash
nano /root/buyoutbot/.env
```

Стрелками дойдите до нужной строки, впишите значение после `=`, затем
`Ctrl+O`, `Enter` (сохранить), `Ctrl+X` (выйти). И перезапустите бота:

```bash
systemctl restart buyoutbot
```

**Проверка Битрикс24:** напишите боту `/bitrix_check`. Ответ «✅ Битрикс24
подключён» и список сотрудников с номерами — всё в порядке.

## Шаг 5. Аккаунт площадки (начинаем с Дрома)

1. Зарегистрируйте **отдельный** аккаунт на drom.ru под выкуп (не тот, с которого
   салон продаёт машины): если площадка ограничит аккаунт, продажи не пострадают.
2. Войти в аккаунт нужно один раз на своём компьютере — на сервере нет экрана:
   - установите Python с python.org (при установке отметьте галочку
     **Add Python to PATH**);
   - скачайте архив бота:
     https://github.com/rzaliev-rin/Aliev/archive/refs/heads/claude/peaceful-dijkstra-2793bo.zip
     и распакуйте;
   - откройте распакованную папку, в адресной строке папки напишите `cmd` и
     нажмите Enter — откроется командная строка;
   - выполните по очереди:

     ```bash
     pip install playwright
     ```

     ```bash
     python -m playwright install chromium
     ```

     ```bash
     python -m buyout.login drom tmn-drom-1
     ```

     (`tmn-drom-1` — любое имя аккаунта латиницей, запомните его);
   - откроется браузер — войдите в аккаунт Дрома (логин, код из SMS), вернитесь в
     командную строку и нажмите Enter.
3. В папке появится файл `buyout_session_drom_tmn-drom-1.json`. **Отправьте этот
   файл новому боту в MAX** (как обычный файл). Бот ответит «✅ Вход сохранён».
   Потом удалите это сообщение из чата — файл даёт доступ к аккаунту.

## Шаг 6. Настройка салона в боте

Всё пишется новому боту в MAX. Пример для одного салона — замените значения на свои.

1. Создать профиль:
   ```
   /buyout_new tmn-toyota Тойота Центр Тюмень
   ```
2. Кто пишет и что ищем:
   ```
   /buyout_set tmn-toyota manager_name=Алексей; address=Тюмень, ул. …; brands=Toyota,Lexus; year_from=2016; price_to=3,5 млн; mileage_max=150000
   ```
3. Выкуп и комиссия:
   ```
   /buyout_set tmn-toyota offer=оба; commission_price_to=8 млн; commission_terms=5% от цены продажи, договор на 45 дней
   ```
4. Ссылка поиска: откройте drom.ru, выберите город, марку, цену и т.д., нажмите
   «Показать». Скопируйте адрес из строки браузера и вставьте:
   ```
   /buyout_set tmn-toyota drom_on=да; drom_url=https://auto.drom.ru/tyumen/toyota/…; drom_account=tmn-drom-1
   ```
5. Битрикс24 для этого салона (необязательно — иначе берутся общие настройки):
   ```
   /buyout_set tmn-toyota bitrix_entity=сделка; bitrix_category=3; bitrix_responsible=15,27
   ```
   Номера сотрудников (15, 27) — из ответа `/bitrix_check`.
6. Рабочий чат: добавьте нового бота в рабочий чат салона в MAX (как участника) и
   напишите **в этом чате**:
   ```
   /buyout_chat tmn-toyota
   ```
7. Проверьте настройки: `/buyout_show tmn-toyota` — внизу будет список, чего ещё не хватает.

## Шаг 7. Проверка и запуск

1. **Песочница** — агент пишет вам, как будто вы продавец; никому ничего не уходит:
   ```
   /buyout_try tmn-toyota
   ```
   Отвечайте командой `/t ваш ответ`, например `/t Да, продаю, а сколько дадите?`.
   Проверьте тон. Для комиссии: `/buyout_try tmn-toyota комиссия`.
2. **Запуск**: `/buyout_on tmn-toyota`. На старте поставьте небольшой лимит:
   `/buyout_set tmn-toyota per_day=10`.
3. **Наблюдение**: `/buyout` — статистика (написали, ответили, готовы, отказы).
   Если площадка покажет капчу или слетит вход, бот остановит её и напишет вам.
4. **Забрать диалог у агента**: `/buyout_mute <ID диалога>` (ID — внизу сообщения
   о клиенте).

## Доступ сотрудникам

Сотрудник пишет боту `/myid` и присылает вам номер. Вы пишете боту
`/admin_add <номер>`. Убрать — `/admin_del <номер>`.

## Если что-то не работает

Выполните на сервере и пришлите вывод разработчику:

```bash
journalctl -u buyoutbot -n 50 --no-pager
```
